## compose-upgrade
`compose-upgrade` is a Bash helper intended to perform safe and repeatable Docker Compose upgrades for administrative environments. In this repository it lives under `src/tools/compose-upgrade/` so that its source, packaging metadata, and manual page remain alongside the APT infrastructure. The tool will be built into a Debian package and published through the APT repository generated into `dist/`. Keeping the source here ensures the monorepo can evolve new administrative tools without scattering their definitions across multiple projects. Future changes should update this README alongside code and packaging to keep behavior and documentation aligned.
