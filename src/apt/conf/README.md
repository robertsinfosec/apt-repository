## APT Repository Configuration
This directory will hold configuration for the tool that assembles the Debian-style repository, likely using reprepro or a similar utility. The configuration stored here will drive creation of `dist/dists/` and `dist/pool/` based on provided `.deb` inputs, without requiring manual edits to generated metadata. Files such as `distributions`, `options`, and `pull` lists will be defined here once the build is implemented. Contributors should treat these files as source of truth for how packages and components are mapped into the repository. Any changes to repository behavior should be made in these configuration files and then rebuilt into `dist/`.
