## Repository Purpose
This repository hosts the source and configuration that produce the Debian and Ubuntu APT repository for robertsinfosec tooling served from https://apt.robertsinfosec.com. All hand-authored materials live in `src/` and `docs/`, while `dist/` holds the deployable files that are published to the hosting environment. The goal is to keep the separation between source and generated output obvious so contributors know where to make changes and what will be overwritten by builds. The first package published here will be `compose-upgrade`, with the structure intentionally flexible enough to support additional tools later. Contributors should treat `dist/` as disposable build output that can be regenerated at any time.

## Using dist/ as the Artifact Tree
The `dist/` directory will be generated by build scripts and CI so that its contents can be deployed directly to https://apt.robertsinfosec.com without manual edits. It will contain the Debian-style `dists/` and `pool/` trees for `apt`, along with the static documentation site under `dist/docs/` and root-level files such as `robots.txt` and `sitemap.xml`. Developers should never hand-edit `dist/`; instead, changes should be made to source files under `src/` or documentation under `docs/`, then rebuilt. The repository layout ensures the build can be run locally or in CI to fully recreate `dist/` from source inputs. When in doubt, update source content and rerun the build rather than patching generated artifacts.
